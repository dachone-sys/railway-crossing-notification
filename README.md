# 🚃 Railway Crossing Notification System
## 踏切事前通知システム

列車の踏切到達時刻を事前にドライバーへ通知することで、  
**踏切の安全性を確保しながら、交通渋滞の軽減を目指すWebシステム**です。

バックエンドに **FastAPI**、フロントエンドに **React + TypeScript** を使用し、  
WebSocketによって列車接近情報をリアルタイムに表示する仕組みを開発しています。

---

## 📌 概要

日本では、踏切を通過する際に車両の一時停止が求められており、
踏切事故を防止するための重要な安全対策となっています。

一方で、列車が接近していない時間帯でも車両が停止することにより、
交通量の多い踏切では車両の流れが滞り、交通渋滞の一因となる可能性があります。

そこで本プロジェクトでは、

**「列車がいつ踏切へ到達するのかを事前に把握できれば、安全性を確保しながら、より効率的な交通制御ができるのではないか」**

という考えから、踏切事前通知システムを開発しています。

---

## 💡 開発背景

現在の踏切では、ドライバーが列車の接近状況を事前に把握することは困難です。

そのため、踏切を通過する車両は列車の接近有無にかかわらず、安全確認のために停止する必要があります。

そこで、列車の位置や走行状況から**踏切へ到達するまでの時間を算出し、その情報をリアルタイムでドライバーへ通知する仕組み**を検討しました。

例えば、

- 列車が十分離れている場合  
  → 列車接近までの残り時間を表示

- 列車が近づいている場合  
  → ドライバーへ注意喚起

- 踏切作動の一定時間前  
  → 停止を促す警告を表示

- 踏切作動中  
  → 通行できないことを表示

といった段階的な情報提供を想定しています。

将来的には、このようなシステムについて十分な安全性・信頼性を検証した上で、

**列車が接近していない場合には一律の一時停止ではなく徐行などの方法を選択できる、新しい踏切交通制御の可能性**

を検討することを目標としています。

本プロジェクトは、単なるWebアプリケーションの開発ではなく、

**「テクノロジーによって踏切の安全性を維持しながら、交通渋滞を軽減できないか」**

という社会課題に対する技術提案・検証を目的としています。

## 🚦 提案する仕組み

想定するシステムの流れは以下です。

```text
列車位置・走行情報
        │
        ▼
踏切到達時間の算出
        │
        ▼
     FastAPI
        │
        │ WebSocket
        ▼
 React / TypeScript
        │
        ▼
踏切付近の表示システム
        │
        ▼
ドライバーへ列車接近状況を通知
```

### 表示イメージ

```text
列車接近まで 120秒
        ↓
    通常表示

列車接近まで 60秒
        ↓
    注意表示

列車接近まで 30秒
        ↓
    停止準備

踏切作動
        ↓
    通行停止
```

※ 上記の時間設定はシステムコンセプトを示すための一例です。

## ▶️ 起動方法

### 1. Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

FastAPIが起動します。

### 2. Frontend

別のターミナルを開き、

```bash
cd frontend
npm install
npm run dev
```

を実行します。

表示されたURLへブラウザからアクセスしてください。
